# Dispatcher chat chime

`admin-chat-chime.wav` is an original synthesized two-note PCM chime, 0.48 seconds, mono 44.1 kHz. It contains no third-party recording. The dispatcher plays it quietly, without looping, at most once every three seconds per signed-in admin in one browser. Other browser profiles/devices may each alert. See issue #120.

The longer `/notification.mp3` belongs to the existing driver order-alert flow and is unchanged.
