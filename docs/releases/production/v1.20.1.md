## Notes

This is the first release recorded under this convention. Its bundle was exported before the exporter accepted `--version`, so its `manifest.json` has no `version` field. This record and the `v1.20.1` tag on the source commit provide the mapping. The version keeps the installed Android 1.20 line and increments the patch because this release changes only the server and dispatcher dashboard. Earlier VPS releases are not retroactively tagged.
