# Tayyn Hyzmat 1.21.2

Android-only update, version code 24. No server, API or database change; production stays on server release 1.21.0.

## English

### What's changing

- Ending a shift and starting it again straight away now works reliably. Before, a quick restart could fail with "Смена уже запущена" and leave you offline.
- On phones without Google Play location services, starting a shift sends one location report instead of two.

### Install or update

Install `TayynHyzmat-production-1.21.2-code24.apk` over the production 1.21 or 1.21.1 app. It uses the same signing identity, so uninstalling is not required. If Android rejects the update, keep the installed app and contact the operator.

## Русский

### Что меняется

- Если завершить смену и сразу снова выйти на линию, это теперь работает надёжно. Раньше быстрый повторный выход мог завершиться ошибкой «Смена уже запущена» и оставить водителя не на линии.
- На телефонах без сервисов геолокации Google при выходе на линию отправляется одно сообщение о местоположении вместо двух.

### Установка и обновление

Установите `TayynHyzmat-production-1.21.2-code24.apk` поверх производственной версии 1.21 или 1.21.1. Подпись та же, удалять приложение не нужно. Если Android отклоняет обновление, сохраните установленное приложение и обратитесь к оператору.
