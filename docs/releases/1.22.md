# Tayyn Hyzmat 1.22

Release candidate, Android version code 25. Final integrated checks, signed artifacts and production rollout are pending. Add the verified APK link and checksum after publication, and record the deployment in [production records](production/README.md).

## Operator notes

- Dispatcher approval of self-registered drivers is restored. `POST /auth/register` creates a pending account and returns a confirmation message without a session. Login is refused with "Ваш аккаунт ожидает подтверждения" until a dispatcher approves the application with `POST /admin/drivers/:id/approve`. The dashboard shows the pending count, which links to the filtered driver list. New applications appear live.
- Dispatcher-created accounts stay approved immediately. Activity records them as "Создан водитель …". Approved applications appear as "Одобрен водитель …". Unblocking stays a separate action, recorded as "Разблокирован водитель …".
- Approve applies only to pending applications. It returns 409 for a deleted account and for a blocked driver; use Unblock for a blocked driver. Approving an approved driver changes nothing.
- 1.21 APKs can still submit applications. The device identity they send is accepted and ignored.
- Production starts fresh: exactly one dispatcher account and the nine canonical regions, with no drivers. No driver data is migrated and there is no special handling for earlier accounts. The database schema is unchanged.
- The password policy is unchanged: 6 characters minimum, 72 UTF-8 bytes maximum, numeric passwords allowed, no trimming.

## English

### What's changing

- To become a driver, submit an application with your name, phone number and password. The dispatcher reviews it. After approval, sign in with the same number and password. Until then, sign-in shows that your account is awaiting approval.
- If your number is already registered, the app asks you to sign in or contact the dispatcher.
- The dispatcher can still create an account for you. That account can sign in immediately.
- All other 1.21 behaviour is unchanged.

### Install or update

The production APK will be published as `TayynHyzmat-production-1.22-code25.apk`. Install it over the installed 1.21.x app (1.21, 1.21.1 or 1.21.2) with the same signing identity. Uninstalling is not required. If Android rejects the update, keep the installed app and contact the operator.

## Русский

Кандидат на выпуск, код версии Android 25. Итоговые проверки, подписанные файлы и обновление рабочего сервера ещё не завершены. Ссылка на APK и контрольная сумма появятся после публикации и проверки.

### Что меняется

- Чтобы стать водителем, отправьте заявку с именем, номером телефона и паролем. Диспетчер проверит её. После одобрения войдите с этим номером и паролем. До одобрения при входе показывается, что аккаунт ожидает подтверждения.
- Если номер уже зарегистрирован, приложение предложит войти или обратиться к диспетчеру.
- Диспетчер по-прежнему может сам создать аккаунт водителя. С таким аккаунтом можно войти сразу.
- Остальные изменения версии 1.21 сохранены.

### Установка и обновление

Производственный APK будет опубликован под именем `TayynHyzmat-production-1.22-code25.apk`. Установите его поверх установленной версии 1.21.x (1.21, 1.21.1 или 1.21.2) с той же подписью. Удалять приложение не нужно. Если Android отклоняет обновление, сохраните установленное приложение и обратитесь к оператору.
