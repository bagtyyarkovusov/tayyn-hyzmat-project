# Tayyn Hyzmat 1.21

Release candidate, Android version code 22. Final integrated checks, signed artifacts and production rollout are pending. Add the verified APK link and checksum after publication. Tracking issue: #141. Verification status is recorded in [the integration checkpoint](../plans/release-1.21-integration.md).

## English

### What's changing

- Create a driver account and sign in immediately, without dispatcher approval. New accounts start offline, with no region and zero balance. The dispatcher can also create an active account for a driver.
- The app finds your location automatically while the location view is open. GPS and connection icons show status. To recover location permission or start a shift, use Online.
- Your location can show a microdistrict or quarter when no street name is available, for example "микрорайон Парахат 7/3, 14" or "квартал Кёши". If no useful address is available, it shows coordinates.
- The full quoted fare is deducted from the driver's balance when the driver accepts an order. Starting and completing the trip do not deduct it again.
- Only the dispatcher can cancel an order. For an accepted trip, the dispatcher chooses Cancel with refund or Cancel without refund. Drivers contact the dispatcher to cancel. The order and trip history show the cancellation result.
- Back and X keep an offer open while acceptance is pending. A Back press during the first second of a new offer no longer dismisses it. If the dispatcher cancels during acceptance, the cancelled order cannot reappear as the current trip.
- Old error messages no longer reappear when you return to Orders. An unsent chat message survives tab changes and clears when you log out.
- A delayed status update cannot put you back online after GPS or connection loss ends the shift. Incoming-order alerts and chat alerts remain available. The old cancellation-review banner and cancellation sound are removed.

### Install or update

The production APK will be published as `TayynHyzmat-production-1.21-code22.apk`. Install it over the production 1.20 app with the same signing identity. Uninstalling is not required. If Android rejects the update, keep the installed app and contact the operator.

### Что меняется

- Создайте аккаунт водителя и сразу войдите, без одобрения диспетчера. Новый аккаунт начинает работу не на линии, без региона и с нулевым балансом. Диспетчер тоже может создать активный аккаунт для водителя.
- Приложение автоматически определяет местоположение, пока открыт экран с местоположением. Значки GPS и связи показывают состояние. Для восстановления разрешения на геолокацию или выхода на линию используйте кнопку «Выйти на линию».
- Если названия улицы нет, в адресе может показываться микрорайон или квартал, например «микрорайон Парахат 7/3, 14» или «квартал Кёши». Если подходящего адреса нет, показываются координаты.
- Полная стоимость заказа списывается с баланса водителя при принятии. При начале и завершении поездки повторного списания нет.
- Отменять заказ может только диспетчер. Для принятой поездки он выбирает «Отменить с возвратом» или «Отменить без возврата». Для отмены водитель связывается с диспетчером. Результат отмены виден в заказе и истории поездок.
- Пока заказ принимается, кнопки Назад и X не закрывают предложение. Нажатие Назад в первую секунду нового предложения больше не скрывает его. Если диспетчер отменил заказ во время принятия, отменённый заказ не появится как текущая поездка.
- Старые сообщения об ошибках больше не появляются при возвращении в Заказы. Неотправленное сообщение в чате сохраняется при смене вкладок и удаляется при выходе из аккаунта.
- Запоздавшее обновление статуса не вернёт водителя на линию после завершения смены из-за потери GPS или связи. Оповещения о заказах и сообщениях сохранены. Старый баннер разбора отмен и звук отмены удалены.

### Установка и обновление

Производственный APK будет опубликован под именем `TayynHyzmat-production-1.21-code22.apk`. Установите его поверх производственной версии 1.20 с той же подписью. Удалять приложение не нужно. Если Android отклоняет обновление, сохраните установленное приложение и обратитесь к оператору.
