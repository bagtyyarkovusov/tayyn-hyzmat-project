# Tayyn Hyzmat 1.21.1

Android-only update, version code 23. No server, API or database change; production stays on server release 1.21.0.

## English

### What's changing

- Starting a shift no longer flashes the connection icon red and yellow. It stays green while the dispatcher connection is up. A real connection loss still shows yellow, then red.
- The GPS and connection icons have no background circles. They have more space between them and sit further from the shift button.
- The balance is larger and bold, so it is easier to read.

### Install or update

Install `TayynHyzmat-production-1.21.1-code23.apk` over the production 1.21 app. It uses the same signing identity, so uninstalling is not required. If Android rejects the update, keep the installed app and contact the operator.

## Русский

### Что меняется

- При выходе на линию значок связи больше не мигает красным и жёлтым. Он остаётся зелёным, пока связь с диспетчером есть. При настоящей потере связи значок по-прежнему становится жёлтым, затем красным.
- У значков GPS и связи больше нет круглого фона. Между ними больше места, и они дальше от кнопки выхода на линию.
- Баланс крупнее и жирнее, его легче читать.

### Установка и обновление

Установите `TayynHyzmat-production-1.21.1-code23.apk` поверх производственной версии 1.21. Подпись та же, удалять приложение не нужно. Если Android отклоняет обновление, сохраните установленное приложение и обратитесь к оператору.
