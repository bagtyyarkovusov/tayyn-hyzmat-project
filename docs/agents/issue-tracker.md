# Issue tracker

Issues and specs live in [bagtyyarkovusov/tayyn-hyzmat-project](https://github.com/bagtyyarkovusov/tayyn-hyzmat-project/issues). Use `gh` inside this clone, or pass `--repo bagtyyarkovusov/tayyn-hyzmat-project` explicitly.

Read with `gh issue view <number> --comments`; list with `gh issue list --state open --json number,title,body,labels`. Create with `gh issue create --title "..." --body-file <path>`. Use a file for multiline bodies. Update labels with `gh issue edit`, and close after the acceptance criteria are met.

When a skill says publish to the issue tracker, create an issue here. When it says fetch the relevant ticket, read that issue and its comments.

## Pull requests as a triage surface

PRs as a request surface: no.

External pull requests are not feature requests in the triage queue. Implementation pull requests may link the issue they resolve.
