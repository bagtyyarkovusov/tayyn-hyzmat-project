# Краткая записка для клиента Tayyn Hyzmat

Пилот прошёл путь от простого браузерного прототипа к проверяемой системе для диспетчера и водителя.

Диспетчер создаёт заказ с номером клиента, районом и ценой в TMT. Заказ можно отправить всем водителям или выбрать одного. Водитель сам принимает предложение. Баланс проверяется до принятия, отрицательный баланс не допускается. Если поездка осталась открытой после начала, диспетчер может закрыть её с обязательным указанием причины.

Карта и список водителей работают вместе. Диспетчер может найти водителя, увидеть последнюю точку и открыть действия без полной перезагрузки списка. GPS определяет район. Поиск адреса является дополнительным и при ошибке или исчерпании квоты показывает координаты.

Основные сценарии заказа, личного предложения, баланса, возврата, чата и восстановления проверены в браузере и тестовом APK. Слитые изменения уже находятся в общей Railway-среде. Устаревшие задачи в GitHub закрыты, активные продолжения сохранены.

Перед выпуском остаются: новые статусы готовности к выходу на линию, отдельный экран входа водителя, настройка расширения личного предложения после 20 секунд, production-квота адресов, аналитика «Сегодня» и проверка физического Infinix Android 14 с заблокированным экраном и энергосбережением. На тестовом этапе реальные платежи отключены.
